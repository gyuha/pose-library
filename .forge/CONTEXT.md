# 포즈 라이브러리

캐릭터 포즈를 3D 마네킹(male/female GLB)으로 보여 주고, 그 포즈를 이미지와 자연어 프롬프트로 내보내는 앱의 용어집입니다.

## Language

**포즈 썸네일**:
갤러리에서 사용자가 눌러 포즈를 고르는 이미지입니다. 이 프로젝트의 마네킹 모델로 직접 렌더한 것만 씁니다.
_Avoid_: 캐릭터 이미지, 외부 이미지, 사이트 이미지

**포즈 파일**:
뼈마다 회전값을 담은 포즈 하나의 JSON입니다(`poses/<id>.json`). 형식은 다른 팀이 소유한 포즈 스키마를 따릅니다.
_Avoid_: 포즈 데이터, 클립

**포즈 카탈로그**:
포즈 id마다 한국어 이름, 태그, 정식 설명을 담은 사이드카 목록입니다. 포즈 파일과 따로 관리합니다.
_Avoid_: 메타데이터 파일, 인덱스

**정식 설명**:
사람이 쓴 한국어 포즈 설명 한두 문장으로, 포즈 프롬프트의 첫머리가 됩니다.
_Avoid_: canonical description, 캡션

**포즈 프롬프트**:
클립보드로 복사되는 한국어 텍스트입니다. 정식 설명, 관절에서 도출한 구조화 상세, 성별 문구, 앵글 문구로 이루어집니다.
_Avoid_: 캡션, 설명문

**앵글 프리셋**:
정면, 위, 아래, 옆, 사선 중 하나로 고정된 카메라 위치입니다. 현재 앵글은 PNG 구도와 프롬프트의 앵글 문구를 결정합니다.
_Avoid_: 뷰, 시점 모드

**레퍼런스 사이트**:
UX(앵글 구성, 마네킹 스타일, 탐색 방식)를 참고하고, 포즈를 저작할 때 이미지를 한 장씩 참고 자료로 보는 외부 포즈 갤러리(ai-pose-gallery.pages.dev)입니다. 사이트 이용 조건에 따라 일괄 다운로드는 하지 않고, 이미지는 저장소에 넣거나 재배포하지 않습니다. 저장소에는 직접 만든 관절 회전값만 남깁니다(2026-11-06 사용자 결정으로 변경).
_Avoid_: 원본, 소스 데이터
